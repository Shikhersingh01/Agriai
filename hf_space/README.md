# 🌾 AgriAI: North India Crop & Fertilizer Prediction System

A production-ready Machine Learning system tailored for North India (Punjab, Haryana, UP, Rajasthan) to predict crop yields and recommend optimal fertilizers. The system features a powerful XGBoost ensemble model, dynamic weather auto-fetching via Open-Meteo API, and an interactive Gradio web interface.
